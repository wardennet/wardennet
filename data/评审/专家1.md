# 一、spec.md 问题 &amp; 修改建议（规格说明书）
## 1. 发现的缺陷（轻微漏洞）
### 1.1 优先级链书写错误（关键 BUG）
你文档写的优先级：
```
系统全局白名单 &gt; 租户私有白名单 &gt; Agent 本地配置白名单
```
**正确架构约定优先级应该是：**
```
Agent本地白名单 &gt; 系统全局白名单 &gt; 租户私有白名单
```
原因：
**本地白名单是用户服务器本地最高信任，优先级绝对高于云端所有白名单**
你现在写反了，开发会直接写反逻辑，造成误封解不开。

### 1.2 缺失一条核心规则：白名单 **永久豁免封禁** 的兜底逻辑
spec 没写：
> 白名单IP即使被判定为 L3 高危，**依然强制豁免，不拉黑、不下发**

需要补全，否则开发会出现「高危IP覆盖白名单」BUG。

### 1.3 缺失：全量同步时必须**覆盖完整白名单快照**
你现在只写了黑名单全量同步，**没写白名单全量同步**
会导致：Agent重启、快照损坏、全量同步后本地白名单丢失。

### 1.4 接口校验缺失：白名单TTL字段校验
所有白名单接口**必须校验 TTL 不能为负数、不能超限**
目前 spec 无约束，会产生脏数据。

### 1.5 缺失一条红线规则
当前 spec 红线缺少：
> **云端绝对不会主动删除任何历史攻击日志/威胁记录，白名单仅做运行时豁免**

## 2. spec.md 建议增补/修正清单（可直接改）
1. **修正优先级链为正确顺序**
2. 补充：全量同步同步完整白名单快照
3. 补充：白名单无视威胁等级，强制豁免
4. 补充：白名单 TTL 参数校验规则
5. 补充：云端不删除历史数据规则

# 二、tasks.md 问题 &amp; 修改建议（任务拆解）
## 1. 整体评价
任务拆分**非常完美、粒度精准、分层规范**，是标准企业级开发任务。

## 2. 发现少量缺失 &amp; 漏洞
### 2.1 Agent 任务缺失：本地白名单**永久优先覆盖云端**校验任务
任务里写了优先级，但**没有专门验收任务**，容易漏开发。

### 2.2 Diff 同步任务缺失：白名单 remove 触发本地解封
现在任务只写黑名单 remove，**白名单过期/取消 需要生成 remove 同步本地**，当前缺失。

### 2.3 缺少：白名单命中后**跳过本地检测、跳过云端打分**双端逻辑任务
目前只写了本地跳过，**云端打分引擎也必须跳过**，否则数据库依然涨分、降级后误封。

### 2.4 插件模式缺陷描述不全
需要补充：
> 无插件模式：**完全禁用云端上报、同步、鉴权、远程指令**，100%纯本地

# 四、三份文档统一的 4 个隐性BUG（必须统一修复）
## BUG1：优先级写反（最严重）
### 当前错误
全局白名单 &gt; 租户白名单 &gt; 本地白名单

### 正确最终架构（我们全程沟通定稿）
**本地白名单 &gt; 全局白名单 &gt; 租户白名单**

## BUG2：白名单仅本地跳过，云端未跳过打分
会造成：
白名单IP依然累积威胁分数 → 移出白名单瞬间直接L3拉黑

## BUG3：全量同步不同步白名单快照
Agent重启白名单丢失，严重功能缺陷

## BUG4：无白名单TTL参数校验
可传入负数、超大值，脏数据泛滥
