关于 WardenNet

我们是谁，为什么做这件事，以及未来要走向哪里

WardenNet — 卫枢

让孤岛连成防线

"Every server is a sentinel. Together, they are an army."

每一台服务器都是一个哨兵。当它们孤立时，只能各自为战；但当它们连接成网，就成了一支军队。

WardenNet 的使命很简单：让每一台Web服务器都拥有一双警觉的眼睛，让每一次攻击都无处遁形。

我们相信，安全的本质是协作。一个IP是否恶意，不应由一台服务器独自判断；而应该由整个网络共同见证、交叉验证、集体决策。

WardenNet，让孤岛连成防线。

项目背景

为什么我们要构建 WardenNet

作为中小站长，你一定遇到过这样的困境：服务器几乎每天都在被扫描——目录探测、漏洞扫描、后门爆破，来者不速，成本却实实在在。

商业 WAF 动辄数千元/月，对个人站长和中小企业是沉重负担；而网上零散的开源防护脚本，大多是单机孤岛，各扫门前雪，没有联防机制，容易被攻击者逐个击破，更缺乏专业的误报控制。

WardenNet 的解决方案是：构建一个轻量、开源、可单机独立运行的防御 Agent，并在此基础上叠加云端协同能力。一台服务器被攻击，全网节点共享威胁情报，让每台机器都成为你的哨兵。

项目定位

开源 Agent + 闭源 Cloud SaaS 混合模式

🔓

开源 Agent（agent/）

边缘检测节点，单机永久免费可用。Go 编写的单二进制，零运行时依赖。涵盖滑动窗口检测、5 维评分引擎、ipset/iptables 封禁等核心防护逻辑。开源透明，接受社区审计。

☁️

闭源 Cloud SaaS

云端协同中枢，提供节点间威胁情报交换、独家智能防投毒算法、安全双向鉴权、租户隔离与智能同步等增值能力。三阶段特征架构、智能同步引擎为闭源 CloudPlugin 插件，授权商业使用。

核心承诺

无论是否使用云端服务，Agent 单机模式都永久免费、功能完整、无任何后门。Cloud SaaS 是可选增值，不使用云端也能独立防护。

品牌价值观

透明、协作、轻量、智能

🔓

透明

Agent 核心完全开源，每一行代码都可审计。配置、日志、决策过程对用户完全可见，不做任何黑盒决策。

🤝

协作

安全的本质是协作。一个 IP 是否恶意，不应由一台服务器独自判断，而应该由整个网络共同见证、交叉验证、集体决策。

💨

轻量

Go 单二进制部署，零运行时依赖，内核级 ipset/iptables 封禁。资源占用极低，不影响业务性能。

🧠

智能

基线自学习检测引擎 + 5 维一致性评分模型，精准识别扫描器、爬虫和恶意攻击，多层防误杀机制保障业务连续性。

发展路线图

从 MVP 到企业级，持续演进

v0.1（MVP）已发布

Agent 基础检测框架、滑动窗口模型、ipset/iptables 内核级封禁。单机即可运行，覆盖目录扫描、漏洞探测、后门爆破三大场景。

v0.2已发布

云端 SaaS 架构上线，独家智能防投毒算法、安全双向鉴权打通节点间通信。开启协同防御初版。

v0.3已发布

三阶段特征架构落地（原始/聚合/决策），租户级数据隔离，基于增量的 Diff 同步替代全量推送，云端吞吐大幅优化。

v0.4（当前）进行中

CloudPlugin 闭源插件体系，智能同步引擎（特征库 + 威胁事件），为后续商业化和多形态集成打基础。

未来规划中

企业级功能（SSO、审计日志、自定义特征市场）、私有化部署版本、更多防御场景扩展。

开源协议

清晰的授权边界，保护开发者与商业利益

📄

Agent / 开源部分

AGPLv3 协议发布，代码托管于 GitHub 对应仓库（不含 libcloudplugin/ 闭源目录）。允许自由使用、修改、分发，修改后必须以相同协议开源。

🔐

Cloud SaaS / 闭源插件

Cloud SaaS 后台与 CloudPlugin 商业插件闭源，受商业授权保护。三阶段特征架构、智能同步引擎等核心协同逻辑位于闭源层。

注意

商业用户如需将 CloudPlugin 集成到自有产品，需联系我们获取商业授权。擅自反编译、逆向或分发闭源插件将承担法律责任。

合规声明

明确能力边界，合规透明使用

⚠️
免责边界

WardenNet 专注于 Web 应用层威胁检测与 IP 封禁，不提供网络层带宽防护。以下能力不在本产品覆盖范围内，请勿对号入座：

❌

不提供网络层带宽防护

SYN/UDP 洪水攻击、带宽耗尽型 DDoS、四层会话耗尽等需要依赖云厂商硬件清洗、高防 IP 或运营商级防护。

⏱️

IP 数据 TTL 自动过期

云端威胁情报与本地封禁记录均设置 TTL（24-72 小时），过期自动清除，不长期留存 IP 行为画像。

🌏

暂不支持海外 SaaS

Cloud SaaS 服务目前仅面向国内地区提供，海外节点暂不接入。如有需求请联系我们评估私有化方案。

合规使用建议

请遵守所在地区法律法规。WardenNet 产生的封禁与情报数据仅用于防护目的，不得用于任何违规用途。使用者须自行承担不当使用的法律责任。
