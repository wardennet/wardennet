配置详解

WardenNet Agent 通过 YAML 文件驱动所有运行参数。配置文件路径默认为 /etc/wardennet/config.yaml，可通过 --config 参数覆盖。

💡 热重载
Agent 每 5 秒自动轮询配置文件变化并热重载，修改后无需重启。但新增或删除 log_sources 中的日志源需要重启。

配置文件结构一览

YAML（完整结构）
# 顶级 section 概览
agent:           # Agent 基础参数（TTL 等）
log:              # 日志输出配置
stats:            # 统计报告
log_sources:       # 日志源采集
detector:         # 基线自学习检测引擎
port_scan:        # 端口扫描检测
ipset:           # IP 黑白名单
unix_socket:      # CLI 通信 UnixSocket
cloud:            # 云端协同

agent 段

Agent 基础参数，控制本地 TTL 行为。

参数类型默认值说明
local_block_ttlint (秒)3600本地检测触发的默认封禁时长（3600=1 小时，259200=72 小时）
cloud_block_ttlint (秒)7200云端下发封禁的 TTL 上限（超过此值自动截断）
cloud_max_ttlint (秒)86400云端下发最大 TTL 上限（1 天）

log 段

日志输出配置，使用 lumberjack 实现自动轮转。

参数类型默认值说明
levelstringinfo日志级别：debug（输出每个请求的详细打分）/ info（推荐生产环境）/ warn / error
filestring""日志文件路径，空字符串表示仅输出到 stdout。建议生产环境设置为 /var/log/wardennet/agent.log
max_sizeint (MB)100单个日志文件最大体积，超过后自动轮转
max_backupsint7保留的旧日志文件数量
max_ageint (天)30旧日志文件保留天数
compressbooltrue是否用 gzip 压缩旧日志文件

log_sources 段

日志源采集配置。每个日志源可以是不同类型的 Web 服务器日志，Agent 会同时 tail 所有配置的日志源。

参数类型说明
pathstring日志文件绝对路径
parserstring内置解析器：nginx_access / apache_access / tomcat_access / linux_auth / custom
YAML
log_sources:
  nginx_access:
    path: /var/log/nginx/access.log
    parser: nginx_access

  apache_access:       # 可选
    path: /var/log/apache2/access.log
    parser: apache_access

  tomcat_access:       # 可选
    path: /usr/local/tomcat/logs/localhost_access_log.txt
    parser: tomcat_access

  linux_auth:          # SSH/登录审计
    path: /var/log/auth.log
    parser: linux_auth

detector 段

这是最核心的配置段，控制基线自学习检测引擎的行为。

核心阈值

参数类型默认值说明
enabledbooltrue检测引擎总开关。关闭后 Agent 仍然 tail 日志但不计分。
modestringblock运行模式：block（正常封禁）/ report（观察者模式，只评分不上报不封禁）
sensitivitystringmedium灵敏度分档：high（偏离 P95 2x 即触发）/ medium（5x）/ low（10x）
score_highint50触发封禁的风险分阈值。实际评分 ≥ 此值时执行封禁
score_mediumint30中等风险阈值，用于 Consistency 降权 gate
score_lowint15低风险阈值，仅统计记录

绝对特征权重

3 个维度不参与基线学习，使用固定权重。

参数类型默认值说明
weights.dangerous_patternint5危险攻击模式命中（SQL 注入/XSS/路径遍历等）的权重。单次上限 25 分。
weights.dangerous_methodint3危险 HTTP 方法（CONNECT/TRACE/DELETE/PUT/PATCH）的权重。
weights.file_uploadint20危险文件上传（.php/.jsp/.phtml 等可执行文件）的权重。单次即可能触发封禁。

三档窗口

三个并行的滑动窗口，每个窗口独立维护 P95 基线。取三档中最高分作为最终评分。

窗口size检测目标
10 秒10突发扫描、CC 攻击、暴力破解
30 秒30常规扫描、漏洞探测
60 秒60慢速分布式扫描、低频攻击

三段式特征列表

known_http_clients、sensitive_paths、dangerous_patterns 三个列表支持双格式 + 云端合并。

YAML（格式二：结构化，推荐）
known_http_clients:
  local: ["custom-client"]       # 业务特有的 HTTP 客户端 UA
  excludes: ["internal-probe"]    # 排除确实存在的业务 UA
  disable_builtin: false        # 禁用内置默认值（慎用）
  disable_cloud: false          # 禁用云端拉取（调试用）

sensitive_paths:
  local: ["actuator", "swagger-ui"]
  excludes: ["env", "admin"]

dangerous_patterns:
  local: ["select ", "../", "127.0.0.1"]
  excludes: []

合并规则：Builtin（代码默认） + Local（YAML 追加） + Cloud（云端拉取） → 去重 → 排除 Excludes → 最终列表

跳过路径列表（skip_paths）

匹配的路径在 Process() 最前端直接跳过，完全不参与检测。支持精确匹配和前缀匹配。

YAML
detector:
  skip_paths:
    - /favicon.ico            # 浏览器自动请求
    - /robots.txt             # 爬虫自动请求
    - /.well-known/           # ACME/Let's Encrypt
    - /api/health             # 你的健康检查端点
    - /static/                # 静态资源前缀
    - /browser-specific-path
💡 默认跳过
即使你不配置 skip_paths，Agent 也会自动跳过 /favicon.ico、/favicon.png、/robots.txt、/.well-known/。

port_scan 段

端口扫描检测，独立于 HTTP 日志，直接监听网络层 SYN 包。默认关闭。

参数类型默认值说明
enabledboolfalse端口扫描检测总开关
sourcestringauto数据源：auto（自动检测）/ iptables（优先）/ pcap（跨平台）
log_pathstring/var/log/syslogiptables LOG 输出路径
log_prefixstring[PORT_SCAN]: iptables LOG 规则中的 --log-prefix 必须匹配
block_ttlint (秒)3600端口扫描 IP 的封禁时长
weightint30触发封禁的权重阈值

端口扫描窗口配置

YAML
port_scan:
  windows:
    - size: 5     max_ports: 5    # 5 秒内扫 5 个不同端口 → 触发
    - size: 30    max_ports: 15   # 30 秒窗口
    - size: 120   max_ports: 40   # 120 秒慢速扫描

ipset 段

参数类型默认值说明
whitelistlist127.0.0.1, ::1本地白名单，命中的 IP 跳过所有检测。支持精确 IP、CIDR 网段、IPv6 地址。优先级最高。
blacklistlist[]预加载黑名单（断网兜底）。一般留空，由检测引擎自动添加。
YAML
ipset:
  whitelist:
    - 127.0.0.1                    # 本机回环
    - ::1                                 # IPv6 回环
    - 192.168.1.0/24                  # 内网网段
    - 10.0.0.0/8                    # 内网大网段
    - 203.0.113.50                # 单个运维 IP
    - 104.16.0.0/12                # Cloudflare CDN 段
  blacklist: []
⚠️ 白名单优先级
白名单是绝对豁免。命中白名单的 IP 不会被任何机制封禁，包括云端下发。即使使用 force: true 强制封禁也会被跳过（除非用 CLI force: true）。

cloud 段

云端协同配置，用于对接 Cloud SaaS。单机模式留空即可。

参数类型默认值说明
enabledboolfalse云端协同总开关。关闭时 Agent 纯本地运行。
base_urlstring""WardenNet 控制台 HTTPS 地址，结尾不带 /
tenant_idstring""租户标识，由控制台创建租户时颁发
agent_secretstring""Agent 鉴权密钥。建议通过环境变量 WARDENNET_AGENT_SECRET 注入避免落盘。
plugin_pathstring/usr/lib/wardennet/libcloudplugin.soCloudPlugin .so 文件路径

unix_socket 段

参数类型默认值说明
pathstring/var/run/wardennet.sockCLI 通信 Unix Socket 路径。权限 0600，仅 root 可访问。

stats 段

参数类型默认值说明
report_intervalint (秒)60统计报告间隔。设为 0 禁用周期性报告。

参数变更生效时机

参数类型生效时机是否需要重启
detector.*（阈值、权重、灵敏度等）下次评分计算时否
known_http_clients / sensitive_paths / dangerous_patterns下次匹配时否
ipset.whitelist / ipset.blacklist下次黑白名单同步时否
log.level / log.file下次日志输出时否
skip_paths下次请求处理时否
log_sources 新增/删除—是
unix_socket.path—是
