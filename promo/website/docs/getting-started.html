快速上手

本指南带你用 3 步 从零跑通 WardenNet Agent，让你的服务器立即获得 Web 攻击防护能力。整个过程大约 5 分钟。

💡 单机模式即插即用
Agent 是开源的、单机可独立运行的防护引擎。没有 CloudPlugin 也完全不影响本地防护能力。

前置条件

组件要求安装命令
操作系统Linux（Ubuntu 20.04+ / Debian 11+ / CentOS 7+）—
ipset≥ 6.xapt install ipset 或 yum install ipset
iptables≥ 1.8.xapt install iptables
Go≥ 1.21（仅编译需要）apt install golang-go
权限root（操作 ipset/iptables 需要）—

第 1 步：编译 Agent

在你的开发机或服务器上克隆仓库并编译：

Shell
# 克隆仓库
git clone https://github.com/wardenet/wardenet.git
cd wardenet/agent

# 编译 Linux 二进制（交叉编译，Windows/Mac/Linux 均可）
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
go build -o wardennet_linux ./cmd/wardennet

# 编译完成后查看产物大小
ls -lh wardennet_linux
# 预期：非常轻量
💡 预编译二进制
如果你不想编译，可以从 GitHub Releases 下载预编译好的 wardennet_linux 二进制文件。

第 2 步：准备配置

复制示例配置文件并做最小修改：

Shell
# 创建目录
mkdir -p /opt/wardennet /etc/wardennet /var/log/wardennet

# 复制二进制
cp wardennet_linux /opt/wardennet/wardennet
chmod +x /opt/wardennet/wardennet

# 复制配置
cp configs/wardennet.yaml.example /etc/wardennet/config.yaml

编辑配置文件 /etc/wardennet/config.yaml，这是一个最小可用的单机模式配置：

YAML
# 单机模式最小配置示例

agent:
  local_block_ttl: 3600   # 封禁 1 小时后自动解封

log:
  level: info
  file: /var/log/wardennet/agent.log

log_sources:
  nginx_access:
    path: /var/log/nginx/access.log   # 改成你的 Nginx 日志路径
    parser: nginx_access

detector:
  enabled: true
  mode: block
  sensitivity: medium       # high=严格, medium=平衡, low=宽松
  score_high: 50

ipset:
  whitelist:
    - 127.0.0.1
    - ::1

cloud:
  enabled: false  # 单机模式关闭云端
⚠️ 关键：日志路径
log_sources.nginx_access.path 必须指向你服务器上实际的 Nginx access log 路径。常见路径：
  • Ubuntu/Debian: /var/log/nginx/access.log
  • CentOS/RHEL: /var/log/nginx/access.log
  • 宝塔面板: /www/wwwlogs/你的域名.log

第 3 步：运行 Agent

推荐使用 systemd 服务管理 Agent：

Shell
# 创建 systemd 服务文件
cat > /etc/systemd/system/wardenet.service << 'EOF'
[Unit]
Description=WardenNet Agent - 本地恶意扫描防护
After=network.target

[Service]
Type=simple
User=root
Group=root
ExecStart=/opt/wardennet/wardennet --config /etc/wardennet/config.yaml
Restart=on-failure
RestartSec=5s
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target
EOF

# 启动服务
systemctl daemon-reload
