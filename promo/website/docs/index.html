贡献指南

WardenNet 采用部分开源策略。仅 agent/ 目录（不含 libcloudplugin/）接受开源贡献。

⚠️ 闭源组件
Cloud SaaS（cloud/）、Web 前端、spec 文档均为闭源，不接受外部 PR。

开源贡献流程

  1. Fork 项目仓库
  2. 创建功能分支：git checkout -b feature/your-feature
  3. 提交改动：git commit -m "Add your feature"
  4. 推送分支：git push origin feature/your-feature
  5. 发起 Pull Request

开发规范

  • Go 代码遵循官方 Effective Go 规范
  • 所有改动需通过 go test ./... 单元测试
  • 新增功能需补充单元测试用例
  • 配置项变更需同步更新 wardennet.yaml.example
