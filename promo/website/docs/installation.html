安装部署

本指南提供 WardenNet Agent 的多种安装方式，从简单的二进制下载到完整的源码编译，覆盖各种生产环境需求。

系统要求

生产环境（Linux）

组件最低要求推荐配置
操作系统Ubuntu 20.04+ / Debian 11+ / CentOS 7+Ubuntu 22.04 LTS
Linux Kernel4.1+5.x+
ipset6.x7.x+
iptables1.8.x1.8.x+ (legacy)
Go（编译时）1.21+1.24+
内存256MB512MB+
磁盘1GB2GB+（日志轮转）
权限root 用户运行—

安装系统依赖

Ubuntu / Debian
apt update
apt install -y ipset iptables socat
CentOS / RHEL
yum install -y ipset iptables-services

方式一：下载预编译二进制（推荐）

最简单的方式，无需本地 Go 编译环境。

Shell
# 下载最新版本（替换版本号和架构）
wget https://github.com/wardenet/wardenet/releases/download/v0.9.0/wardenet_linux_amd64
# 或者 arm64 服务器
# wget https://github.com/wardenet/wardenet/releases/download/v0.9.0/wardenet_linux_arm64

# 创建目录并安装
mkdir -p /opt/wardennet /etc/wardennet /var/log/wardennet /var/lib/wardennet
mv wardennet_linux_amd64 /opt/wardennet/wardennet
chmod +x /opt/wardennet/wardennet

# 验证版本
/opt/wardennet/wardennet --help

方式二：源码编译

Shell
# 克隆仓库
git clone https://github.com/wardenet/wardenet.git
cd wardenet/agent

# 编译 Linux amd64（Windows/Mac/Linux 均可交叉编译）
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
go build -o wardennet_linux \
    -trimpath \
    -ldflags="-s -w -X main.Version=v0.9.0" \
    ./cmd/wardennet

# 多架构批量编译
for arch in amd64 arm64; do
    CGO_ENABLED=0 GOOS=linux GOARCH=$arch \
        go build -o wardennet_linux_$arch ./cmd/wardennet
done
编译参数作用
CGO_ENABLED=0静态编译，产物无外部 C 库依赖
GOOS=linux目标操作系统
GOARCH=amd64目标架构（ARM 服务器改为 arm64）
-trimpath清除本地绝对路径，防止构建环境泄漏
-ldflags="-s -w"去掉符号表和调试信息，体积缩小 40%
-ldflags="-X main.Version=v0.9.0"注入版本号

systemd 服务配置完整示例

将以下内容保存为 /etc/systemd/system/wardenet.service：

INI
[Unit]
Description=WardenNet Agent - 本地恶意扫描防护
After=network.target
Wants=network-online.target

[Service]
Type=simple
User=root
Group=root
ExecStart=/opt/wardennet/wardennet --config /etc/wardennet/config.yaml
ExecStop=/opt/wardennet/wardennet --config /etc/wardennet/config.yaml stop
Restart=on-failure
RestartSec=5s
LimitNOFILE=65536
LimitNPROC=4096

# 环境变量（可选）
# Environment=WARDENNET_AGENT_SECRET=your-secret-key

# 安全加固（可选）
# NoNewPrivileges=yes
# ProtectSystem=full

[Install]
WantedBy=multi-user.target

安装并启动服务：

Shell
systemctl daemon-reload
