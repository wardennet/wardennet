核心概念

WardenNet Agent 是一个 Go 编写的守护进程，读取 Web 服务器访问日志，通过多层智能评分引擎（特征库 + 统计学 + 形态学 + 行为模式学）识别攻击行为，在 Linux 内核层面（ipset/iptables）实现秒级封禁。
WardenNet 卫枢

开源协同防御网络。一处发现，全网御敌。让每一台服务器都成为你的哨兵。
