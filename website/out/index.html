3 步快速部署

1

第 1 步：编译 Agent

# 克隆仓库并编译
cd agent
go build -o wardennet ./cmd/wardennet
2

第 2 步：准备配置

# 复制配置模板
cp configs/wardennet.yaml.example config.yaml

# 关键配置
detector:
  score_high: 50          # 触发本地拉黑候选
  sensitivity: medium    # 灵敏度分档
  mode: block             # block / report
ipset:
  whitelist:
    - 127.0.0.1
3

第 3 步：启动防护

# 直接运行
sudo ./wardennet -config config.yaml

# 或 systemd 服务
sudo cp configs/wardennet.service /etc/systemd/system/
sudo systemctl enable --now wardennet

⚠️ 能力边界声明

WardenNet 专注于 Web 应用层威胁检测与 IP 封禁，不提供网络层带宽防护。SYN/UDP 洪水、带宽耗尽型攻击仍需依赖云厂商高防服务。
