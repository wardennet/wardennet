6 层智能防御引擎

📡

01

日志采集层

实时读取 Nginx、Apache 等 Web 服务器访问日志，支持自定义正则解析

🎯

02

危险模式解码

基于特征库精准识别 SQL 注入、XSS、命令执行等已知攻击特征

📊

03

统计学基线

滑动窗口统计 QPS 分布、状态码比例等指标，建立站点行为基线，偏离度触发评分提升

🧬

04

形态学一致性

5 维模型（前缀连贯度、新颖度饱和、路径集中度、状态同质性、方法语义）识别扫描器形状

🛡️

05

行为模式学降权

空 Referer 硬封顶、401 降权、协同信号动态调整等多层防误报机制

⚡

06

内核级封禁

通过 ipset + iptables 直接在网络层丢弃，秒级响应零损耗

两种部署模式

🔌 单机模式（默认）

开源 Agent · 单机独立运行

不依赖云端即可运行。读取本地 Web 日志，本地评分本地封禁。适合个人站点、独立博客、单节点企业官网。

  • ✓ 5 分钟部署
  • ✓ 零外部依赖
  • ✓ 永久免费
  • - 无协同防御
🌐 协同模式（可选）

Agent + Cloud SaaS

接入云端后，多节点共享威胁情报。一个 IP 在某台服务器被识别为恶意，全网节点自动获取情报，协同封禁。

  • ✓ 一处发现全网御敌
  • ✓ 智能同步引擎自动更新
  • ✓ 云端风控 + 防投毒算法
  • ✓ 安全双向鉴权
